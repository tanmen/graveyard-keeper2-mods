# Quick Stash（宝箱へしまう）

**`G` を押すと、いまいる場所の宝箱に、すでに入っている品と同じ品を所持品からまとめてしまう** BepInEx プラグイン。
しまった品のアイコンが、自分の体から宝箱へ飛んでいく。
所持品のセルの上で**ホイールを押し込むと、その品をロック**でき、ロックした品は `G` を押しても所持品に残る。

## しまうキー（既定 `G`）

- 「いまいる場所」は右上の地名の枠と同じ場所（ゾーン）。宝箱は、ゲームが所持品の窓でまとめて開く収納
  （シンプルな宝箱・大きな宝箱・道具棚・物資保管庫・庭の保管スペースなど。Stock Finder が数える宝箱と同じ）
- しまうのは、**その場所のどれかの宝箱にすでに入っている品と同じ種類の品だけ**。宝箱に無い品は所持品に残る
- 範囲はゲームの宝箱の窓の「同じ品を全部移す」ボタンと同じ:
  - **重ねられる品だけ**（道具・武器など 1 つずつの品は動かさない）
  - 所持品の**袋の中の品は動かさない**。宝箱の中の袋にも入れない
  - 品質（星）の違う品は別の品
- さらに、**ロックした品**と、**ホットバー（1〜4）に置いた品**は残す
- 同じ品が 2 つ以上の宝箱にあれば、**多く入っている宝箱から埋める**。入りきらない分は所持品に残る
- プレイヤーが入れられない収納と、入れられる品の決まりに合わない収納には入れない（ゲームの宝箱の窓と同じ決まり）
- 押したら右下の知らせに「芝地の宝箱へしまった: 6 種 135 個」のように出す（しまえなかったときは理由を出す）
- しまった品のアイコンが、**自分の体から、入れた宝箱へ弧を描いて飛ぶ**（0.2.0〜）。品 1 種類・宝箱 1 つにつき 1 つで、
  少しずつずらして続けて飛ばす（多いときは先頭の 16 個）。小さい所から膨らんで飛び出し、宝箱の手前で縮みながら消える。
  歩いて画面が動いても宝箱からずれない。HUD より手前・窓より奥に描くので、所持品の窓・宝箱の窓を開いている間は窓に隠れる。
  品は押した時点で宝箱に入っていて、演出は見た目だけ
- 効くのは、**歩いているとき**（移動キーを押したままでもよい）と、**所持品の窓・宝箱の窓を開いているとき**。
  会話・演出・眠り・建築・ESC の窓・制作の窓・文字の入力中は何もしない

## ロック（所持品のセルの上でホイールを押し込む）

- 押した品をロックし、セルの左上に南京錠（ゲームの絵）を出す。もう一度押すと外れる
- ロックは**品の種類ごと**（同じ品の山はまとめてロックされる。品質の違う品は別）
- 所持品の窓の中でだけ切り替わる（宝箱・制作の窓・袋の中のセルでは何もしない）
- **セーブ枠ごと**に `BepInEx/config/QuickStash/locks-<枠>.txt` に残る（押したその場で書く）。ゲームの保存の時点とは結び付けない
- Craft Todo の登録キー（同じホイールの押し込み）はレシピにしか反応しないので、所持品のセルでは重ならない

## キーを選んだ理由

ゲームのキーボードの割り当て（2026-11-22 の既定 38 件）で `W A S D Q E F R T I M P Tab Space Esc 1〜4 左Shift 矢印` は使用済み。
Craft Todo が `F8 F9 ホイール` を使う。Q・WASD の近くで空いているのは `Z X C V G`。0.1.0 は手前の角の `Z` にしたが、
試した本人が `G` の方がよいと言ったので 0.2.0 から `G` にした（2026-11-22）。
設定の `StashKey` で変えられる（例 `Z`・`C`。修飾キー付きなら `G + LeftControl`）。
⚠ 設定ファイルが作られたあとに既定を変えても、手元の設定の値は変わらない（BepInEx は設定ファイルの値を優先する）。

## 設定（`BepInEx/config/tanmen.gk2.quickstash.cfg`）

| 設定 | 既定 | 中身 |
| --- | --- | --- |
| `Keys.StashKey` | `G` | しまうキー |
| `Keys.LockKey` | `Mouse2` | ロックを切り替えるキー（所持品のセルの上で押す） |
| `Stash.KeepHotBarItems` | `true` | ホットバーに置いた品を、ロックしていなくても残す |
| `Stash.Notify` | `true` | しまったときに右下の知らせを出す |
| `Stash.Animation` | `true` | しまった品のアイコンを、自分の体から宝箱へ飛ばす |

## 確かめ方（`<ゲーム>/BepInEx/LogOutput.log`）

| 行 | 分かること |
| --- | --- |
| `Loading [Quick Stash 0.2.0]` | 読み込まれた |
| `パッチ: 成功 2 / 失敗 0` | 差し込みが全部当たった |
| `セーブ枠 Steam_1 のロックを読んだ: N 種` | セーブを読み込んで、その枠のロックを読んだ |
| `しまうキー: 場所 芝地 (…)・宝箱 N 個 → …` | 押したときの場所・宝箱の数・結果（しまった品と数） |
| `しまうキーを受けなかった: 窓 X がいちばん上にある` など | キーを受けなかった理由（理由ごとに 1 度だけ） |
| `ロックした: <id>（<名前>）` | ロックの切り替え |
| `南京錠の絵を引いた: icon_lock 11x13` | セルに出す印の絵が引けた（初めて出したとき） |
| `飛ぶ演出を初めて出した: N 個…・体 (…) → UI (…)・最後の宝箱 <id> の的 (…)` | 飛ぶ演出の数と、体・宝箱の位置を画面に直した値（初めてのとき。アイコンの材質が「なし」なら縁が青いまま） |

⚠ BepInEx の `LogOutput.log` は、ゲームが動いている間は書き出しが溜まって数行しか無いことがある。前の起動の分は、セーブデータの
`Player-prev.log`（Unity のログ）にも同じ行が全部ある。

## ビルド・配置

```bash
dotnet test QuickStash/QuickStash.Core.Tests
dotnet build QuickStash/QuickStash -p:DeployToGame=true
```

mod 本体のビルドにはゲームの導入先が要る（`Game.local.props.example` を写して `Game.local.props` を作るか、`-p:GameDir=...`）。
置き場と ⚠ は [docs/modding.md](../docs/modding.md)。調べたゲームの中身は [docs/game-api-notes.md](docs/game-api-notes.md)。
