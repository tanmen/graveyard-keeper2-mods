# Trade Finder（売り買いの場所）

アイテムのツールチップの一番下に、**その品をどの商人から買えるか**と、**どの商人に売れるか**を足す BepInEx プラグイン。
商人の窓を 1 つずつ開けて確かめなくても、ツールチップを見ればどこへ行けばいいかが分かる。

```
買える: 建築士（町） 12
家具職人（未建設）
売れる: 建築士（町） 9
家具職人（未建設） ♥
ヘルム（ステージ II から）
```

- 「買える」= 商人が売っている品、「売れる」= 商人が買い取る品。ゲームの判定と同じく、商人の**いまの段階**の品の中で、
  売らない・買い取らない品の一覧に無いもの
- 1 行目に「買える: 」、2 行目からは名前だけ。いま取引できる所が先（買えるは安い順・売れるは高い順）
- 名前に居る場所（右上の地名の枠と同じ名前）を添え、そのあとに 1 個の値段（いまの在庫での値。商人の窓のセルと同じ）
- **まだ取引できない所は薄い字**: 町の店をまだ建てていなければ「（未建設）」、商人の段階が上がると扱うなら「（ステージ II から）」
- 売ると幸福が入る商人には、最後に幸福のアイコン
- どの商人も扱わない品には何も足さない

並べ方は 2026-11-23 に本人が図の案から選んだ「1 行ずつ」の形。

## 設定（Mods の窓・`BepInEx/config/tanmen.gk2.tradefinder.cfg`）

ESC の窓の「Mods」（[Mods Menu](../ModsMenu/README.md)）の「Trade Finder」のタブで変えられる。Mods Menu が無くても cfg で変えられる。
どの項目も **いつも（`Always`）/ キーを押している間（`WhileKey`）/ 出さない（`Never`）** から選ぶ。既定は全部「いつも」。
ツールチップには「キーを押すと出る」の案内は出さない。

| 設定 | 既定 | 中身 |
| --- | --- | --- |
| `Display.Buy` | `Always` | 「買える」の行 |
| `Display.Sell` | `Always` | 「売れる」の行 |
| `Display.Unavailable` | `Always` | まだ取引できない所（未建設の店・先のステージ）の行 |
| `Display.Place` | `Always` | 名前に添える居る場所 |
| `Display.Price` | `Always` | 値段 |
| `Display.Happiness` | `Always` | 幸福のアイコン |
| `Keys.HoldKey` | `Shift` | 「キーを押している間」のキー（`Shift` / `Ctrl` / `Alt`。左右どちらでも） |

例: 「Shift を押している間だけ売り買いの場所を出す」なら `Buy` と `Sell` を `WhileKey`。「いつも出すが、未建設の店は Shift の間だけ」なら
`Unavailable` だけ `WhileKey`。ツールチップを出したままキーを押す・離すと、その場で出し直す。

## 商人の範囲

- ゲームの商人の定義（`GameBalance.vendorDefs`）の全部。2026-11-23（v1.012.9）で 19 人: ヤヌアリウス・ヘルム・商人頭・ガンター・司祭・ハロルドと、
  町の店 12 軒（薬屋・錬金術師・八百屋・仕立て屋・家具職人・パン屋・魚屋・宝石商・建築士・鍛冶場・酒場・醸造所）。
  品を扱わない商人（ジャックの工房。注文だけ）と、テスト用の商人は出さない
- 町の店の名前は、段階 1 の建物の名前（薬屋 II になっても「薬屋」）。建てたかどうかは、ゲームが店を建てたときに付ける印（注文の窓に出す商人の印）で見る
- 場所は、商人の絵の物（NPC・町の店の店番）が世界のどこにいるか。見つからなければ名前だけ
- 品は id で見る（品質の星の違う品は別の品。商人も星ごとに扱う）

## 確かめ方（`<ゲーム>/BepInEx/LogOutput.log`）

| 行 | 分かること |
| --- | --- |
| `Loading [Trade Finder 0.1.0]` | 読み込まれた |
| `パッチ: 成功 3 / 失敗 0` | 差し込みが全部当たった |
| `Mods Menu にタブを登録した` | Mods の窓にタブが出る（`Mods Menu が入っていないので…` なら cfg だけ） |
| `商人の定義を写した: N 人（町の店 M・扱う品 K 種）` | 商人の定義が読めた（初めてツールチップを出したとき） |
| `商人: 名前（id・段階 N・場所 …）/ …` | 商人ごとのいまの段階・建てたか・居る場所 |
| `ツールチップに売り買いの場所を初めて足した: <id> 行 N（…）` | 初めて足した品と、商人ごとの判定 |
| `キーで出し直した（初めて）: …` | キーを押す・離してツールチップを出し直した |

⚠ BepInEx の `LogOutput.log` は、ゲームが動いている間は書き出しが溜まって数行しか無いことがある。前の起動の分は、セーブデータの
`Player-prev.log`（Unity のログ）にも同じ行が全部ある。

## ビルド・配置

```bash
dotnet test TradeFinder/TradeFinder.Core.Tests
dotnet build TradeFinder/TradeFinder -p:DeployToGame=true
```

mod 本体のビルドにはゲームの導入先（`Game.local.props.example` を写して `Game.local.props` を作るか、`-p:GameDir=...`）と、
同じリポジトリの `ModsMenu/ModsMenu/ModsMenu.csproj`（参照だけ。配る item には入らず、`DeployToGame` も Mods Menu には渡さない）が要る。
置き場と ⚠ は [docs/modding.md](../docs/modding.md)。調べたゲームの中身は [docs/game-api-notes.md](docs/game-api-notes.md)。
